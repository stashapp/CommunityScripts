# BlackHole

https://discourse.stashapp.cc/t/blackhole/1419

True black, steel-blue hairlines, covers that fade into the card, one blue. Version 3.0 refreshes the theme for Stash v0.31: one border colour and one 6px radius everywhere, a toolbar where every control lines up, quieter card text, and styling for the newer parts of Stash (filter sidebar, selection toolbar, pagination, settings, the Theme Switch menu). Pure CSS, system fonts.
