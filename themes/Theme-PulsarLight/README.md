# PulsarLight

https://discourse.stashapp.cc/t/pulsarlight/1430

This is a community created theme for Stash: the light companion to Pulsar, with a soft pastel backdrop under frosted white glass, dark ink and one blue accent.

Version 1.0 refreshes the theme for Stash v0.31. The backdrop is now drawn in CSS from the original Flower image, so it no longer loads it from imgur. Blue replaces the slate and stock blue that leaked through, cards, menus and dialogs are white glass with hairline edges, and the newer parts of Stash (filter sidebar, selection toolbar, performer header, settings, dialogs, phone layouts) are styled.

The theme will only change the look and feel of the Stash interface. It will not affect any other data.

## Install

1. Open the Plugins panel in settings. (http://localhost:9999/settings?tab=plugins)

2. Find the Theme in the listing, in the default Community repo

3. Click Install
