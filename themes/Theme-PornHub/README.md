# Pornhub

https://discourse.stashapp.cc/t/pornhub/1428

This is a community created theme for Stash with a tube-site look: true black, charcoal boxes, bold white type and one orange for whatever is active.

Version 2.0.0 refreshes the theme for Stash v0.31. It no longer loads the Plex theme's stylesheet from GitHub, so it stands on its own. Orange replaces the stock blue that leaked through (toggles, size slider, links, active view), cards fade from the cover into a charcoal body with centred counts, the top bar stays at the top on phones, and the newer parts of Stash (filter sidebar, selection toolbar, performer header, settings, dialogs, phone layouts) are styled.

The theme will only change the look and feel of the Stash interface. It will not affect any other data.

## Install

1. Open the Plugins panel in settings. (http://localhost:9999/settings?tab=plugins)

2. Find the Theme in the listing, in the default Community repo

3. Click Install
