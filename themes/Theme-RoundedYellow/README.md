# Rounded Yellow

https://discourse.stashapp.cc/t/rounded-yellow/1431

A near-black theme with charcoal cards, large rounded corners and one warm yellow for everything active. Version 2.0 refreshes the theme for Stash v0.31: two radii (6px for controls, 20px for cards, panels, menus and dialogs), the active page in yellow with a yellow underline, yellow-filled primary buttons with dark text, covers that fade into the card above a translucent footer band, bordered toolbar boxes with a yellow-filled active view, yellow toggles and a yellow Settings nav block, and styling for the newer parts of Stash (filter sidebar, selection toolbar, performer header, settings, dialogs). The stock blue no longer shows through.
