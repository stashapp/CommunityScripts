# NeonDark

https://discourse.stashapp.cc/t/neondark/1424

Near-black with a soft blue neon glow on cards, outlined boxes and whatever is active. Version 2.0 refreshes the theme for Stash v0.31: outlined toolbar segments at one height with the count on the pagination row, cards with a glow, centred text and a blue divider above the counts, blue-filled primary actions with dark text, and styling for the newer parts of Stash (filter sidebar, selection toolbar, performer header, settings).
