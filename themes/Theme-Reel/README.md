# Reel

A boutique-streaming look for Stash v0.31+. Neutral charcoal with no colour cast,
wine used only for actions, Libre Caslon titles over Hanken Grotesk, pill-shaped
controls and soft 12px corners.

- Scene cards are 4:3 posters: the cover fills the card and the title, date and
  description sit over a dark fade. Performer cards are 2:3 posters.
- Scene grids fill each row with even columns; the zoom slider still sets the
  size (3 to 4 a row at the default zoom on a 1440px window).
- Studios, tags, galleries and groups use framed tiles.
- Covers the list toolbar, filter sidebar, selection toolbar, pagination, list,
  wall and tagger views, scene and detail pages, stats and settings, at desktop
  and phone widths.
- Fonts are bundled in `assets/fonts` (SIL OFL 1.1), so the theme makes no
  external requests.

Pure CSS; no change to Stash behaviour. Enable one theme at a time.
